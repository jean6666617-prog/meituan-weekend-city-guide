# 周末出逃俱乐部｜城市探索指南

面向高校大学生和年轻城市人群的周末活动推荐网站。根据社交电量、动物人格、兴趣、天气、预算与同行人数，推荐适合独处、轻同行或热闹组局的城市体验。

## 功能

- 三档社交电量与十种城市动物人格切换
- 活动类型、天气、预算、人数动态筛选
- 个性化活动推荐、收藏、加入与发起组队
- 低压力“相处说明书”与队伍氛围匹配
- 动物城市护照、打卡成长、攻略点赞与发布
- 首次访问热门活动弹窗与平滑跳转
- 响应式桌面端与移动端布局

## 本地运行

无需安装依赖，直接打开 `index.html`，或运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 部署

项目为纯静态网站，可直接部署至 GitHub Pages、Cloudflare Pages、Vercel 或 Netlify。
