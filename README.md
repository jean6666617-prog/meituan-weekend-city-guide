# 周末搭子｜城市探索指南

面向大学生的周末活动推荐网站，根据兴趣、预算与同行人数推荐展览、市集、演出和户外活动，并支持组队、收藏、打卡与攻略分享。

## 功能

- 兴趣、预算、人数动态筛选
- 个性化活动推荐与换一批
- 活动收藏、组队加入与发起组队
- 周末打卡内容点赞与攻略发布
- 响应式桌面端与移动端布局

## 本地运行

无需安装依赖，直接打开 `index.html`，或运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 部署

项目为纯静态网站，可直接部署至 GitHub Pages、Cloudflare Pages、Vercel 或 Netlify。
